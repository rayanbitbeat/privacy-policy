《黄铜驿站》隐私政策

更新日期：2026 年 11 月 1 日　生效日期：2026 年 11 月 1 日

《黄铜驿站》（以下简称"本游戏"）由〔开发者名称〕（以下简称"我们"）开发和运营。我们非常重视你的个人信息保护。本政策说明本游戏会处理哪些信息、为什么处理、与谁共享，以及你享有的权利。请在使用本游戏前仔细阅读；如有疑问，可通过文末的联系方式找到我们。

一、本游戏自身不收集个人信息

  • 本游戏不需要注册或登录账号，不收集你的姓名、手机号、身份证号、通讯录、照片等信息。
  • 游戏进度、设置、远征存档只保存在你的设备本地，不会上传到我们的服务器（本游戏没有自己的服务器）。
  • 本游戏没有任何付费内容，不收集支付信息。

二、广告与第三方 SDK

Android 版提供"看广告复活"：战斗失败时你可以自愿观看一段激励视频广告换取一次复活。为此我们接入了以下第三方广告 SDK。只有在你于首次启动时点击"同意"后，这些 SDK 才会被初始化；点击"不同意"不影响正常游戏，只是没有广告复活。

我们通过 SDK 提供的开关明确禁止上述 SDK 获取以下信息：

  • 精确或粗略的地理位置；
  • 电话状态与设备识别码（IMEI、IMSI 等）；
  • Wi-Fi 信息（MAC 地址、BSSID、SSID）；
  • 已安装应用列表；
  • 传感器数据；
  • 外部存储写入。

上述 SDK 由第三方独立处理信息，其处理规则以各自的隐私政策为准。我们会持续关注其合规情况；如发现其违规处理你的信息，将及时停止合作。

小游戏版本（TapTap / 微信 / 抖音小游戏）不接入广告 SDK，也不收集个人信息；平台本身的信息处理适用该平台的隐私政策。

三、Android 权限说明

权限用途
网络访问（INTERNET）加载与播放广告
读取网络状态（ACCESS_NETWORK_STATE、ACCESS_WIFI_STATE）判断当前是否联网、网络类型，以便决定是否加载广告；不读取 Wi-Fi 名称或 MAC 地址
振动（VIBRATE）战斗中的震动反馈
保持唤醒（WAKE_LOCK）游戏或广告播放时防止屏幕熄灭
广告标识符（OAID 相关权限）获取可重置的匿名广告标识符，用于广告频次控制与反作弊

本游戏不申请定位、通讯录、相机、麦克风、电话、短信、存储、读取应用列表等权限。

四、信息的存储与保护

  • 游戏存档保存在你的设备上，卸载游戏或清除应用数据后即被删除。
  • 第三方 SDK 处理的信息存储在中华人民共和国境内，保存期限与安全措施以其隐私政策为准。

五、你的权利

  • 撤回同意：在系统"设置 → 应用 → 黄铜驿站 → 存储"中清除数据后重新打开游戏，隐私说明会再次出现，此时选择"不同意"即不再加载广告 SDK（注意：清除数据也会删除游戏存档）。卸载游戏同样会停止一切处理。
  • 关闭个性化广告：可在手机系统设置中关闭"个性化广告"或重置 / 关闭广告标识符（OAID），各品牌手机的入口略有不同，一般位于"隐私"或"广告与隐私"中。
  • 查询、更正、删除：本游戏不在服务器上保存你的个人信息；对第三方 SDK 处理的信息，你可以依据其隐私政策行使权利，也可以联系我们协助处理。

六、未成年人保护

本游戏适合各年龄段玩家，不含付费内容。若你是未满 14 周岁的未成年人，请在监护人的陪同下阅读本政策，并在取得监护人同意后再同意隐私说明、观看广告。监护人如对未成年人的信息处理有疑问，请联系我们。

七、本政策的更新

我们可能因接入的 SDK、游戏功能或法律法规的变化更新本政策，更新后会在本页面公布并修改顶部的更新日期；如有重大变化（例如新增收集信息的类型），我们会在游戏内再次征得你的同意。

八、联系我们

如对本政策或你的个人信息有任何疑问、意见或投诉，请发送邮件至 〔联系邮箱〕，我们会在 15 个工作日内回复。
